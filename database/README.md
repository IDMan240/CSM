Calibration Management System

This directory contains the database schema and documentation for the Calibration Management System.

Database Structure

The database contains 11 tables:

- "gauge_calibrations"
- "gauge_calibration_readings"
- "gauge_equipment_settings"
- "nuprc_settings"
- "recorder_calibrations"
- "recorder_calibration_readings"
- "recorder_equipment_settings"
- "system_settings"
- "users"
- "valve_certificates"
- "valve_equipment_settings"
- "valve_physical_checks"
- "valve_pressure_log"

Schema File

"schema.sql" contains the database table definitions, indexes, and relationships.

Security

- No production records are included.
- No live database credentials are included.
- Production user information is not published.

Purpose

This database supports calibration record management, equipment settings, user management, and calibration-related operations.
